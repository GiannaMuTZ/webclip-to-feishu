WEBCLIP / LOCAL BRIDGE

把有价值的网页，
变成可编辑的飞书文档。

正文、公式、表格，各自回到合适的位置。

01 / 配置

连接飞书

运行 npm run setup，在 .env 中填写应用和文件夹信息。详细步骤见项目中的 docs/FEISHU_SETUP.md。

02 / 安装

加载浏览器扩展

在 Chrome/Edge 扩展管理页启用开发者模式，加载项目中的 dist/extension 文件夹，填写配对码。

03 / 保存

打开网页，提取预览

选择正文、选区或页面主体。检查公式和表格后，点击「保存到飞书」。关闭弹窗，任务仍会继续。

打开公式与表格演示页 ↗

本地服务已启动。此页只展示使用说明；飞书连接状态可在扩展中检查。
