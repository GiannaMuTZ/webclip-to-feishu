# Webclip · 网页到飞书

把浏览器当前网页或选中内容保存为**可编辑的飞书云文档**：保留公式、表格、标题、代码和来源链接。

Chrome / Edge Manifest V3 扩展 + Node.js 本地服务。无需读取飞书 Cookie，无需 AI API。

## 能做什么

| 内容 | 导入方式 |
| --- | --- |
| 正文 / 选区 / 页面主体 | 三种提取范围，保存前预览 |
| KaTeX、MathJax、LaTeX 分隔符 | 恢复 TeX，写入飞书原生 `equation` 元素 |
| 基础 MathML | 转为 TeX；不能可靠转换时显示提示 |
| HTML 表格 | 飞书原生表格，保留行列、表头、`rowspan` / `colspan` 和单元格公式 |
| 标题、列表、引用、粗体、斜体、链接 | 转为对应文档块和富文本 |
| 代码 | 转为代码块，美元符号不作为公式处理 |
| 长文和大表格 | 文本分块，表格按每片最多 100 行 × 9 列分片 |
| 导入任务 | 后台排队、进度查询、任务去重、部分失败文档链接 |

## 快速开始

需要 Node.js 22 或更新版本、Chrome/Edge、飞书自建应用。

```bash
npm ci
npm run setup
npm run build
npm start
```

1. 按 [飞书配置教程](docs/FEISHU_SETUP.md) 创建应用、授权文件夹，在本地 `.env` 中填写三个 `FEISHU_` 配置项。修改后重启服务。
2. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`，启用开发者模式，点击「加载已解压的扩展程序」，选择本项目的 `dist/extension`。
3. 点击扩展图标，在「连接设置」中填写 `.env` 的 `BRIDGE_TOKEN`，端口默认为 `17321`。
4. 打开网页 → 点击扩展 → 选择范围 → 提取并预览 → 保存到飞书。

还没有飞书应用也能测试提取预览。先运行 setup、build、start，配置扩展配对码，再打开 [本地演示页](http://127.0.0.1:17321/demo.html)。演示包含行内/行间公式、MathML、合并表格、代码和价格文字。

关闭扩展弹窗后，**本地服务保持运行时**导入会继续；重新打开弹窗可查看上次任务。失败时先检查部分文档，再重新提取创建新任务。不要反复创建新任务来重试同一批内容。

## 为什么这样设计

```mermaid
flowchart LR
    A[已打开的网页或选区] --> B[浏览器扩展读取 DOM]
    B --> C[本地提取与公式规范化]
    C --> D[预览与格式提示]
    D --> E[异步导入队列]
    E --> F[飞书文档与原生内容块]
```

- 读取当前浏览器 DOM：使用你已经能访问的内容，不需要服务端重新登录网站。
- 先恢复公式源码，再提取正文：避免 KaTeX 的视觉层和辅助层被重复复制，或 TeX 注解被正文清理删掉。
- 使用原生公式、原生表格：导入后可以继续编辑，不把核心内容固定为截图。
- 密钥放本地服务：扩展只持有本机配对码，App Secret 不进入网页和扩展包。
- 只在明确限流或 token 被拒绝时重试：网络中断和 5xx 可能发生在写入之后，盲目重试会重复创建文档或内容块。

## 开发与验证

```bash
npm run check     # TypeScript 检查、构建、单元和本机 HTTP 集成测试
npm run dev       # 修改服务代码后自动重启；静态页面需先 build
npm run package   # 构建并输出 release/webclip-extension-0.1.0.zip
```

修改扩展后运行 build，并在浏览器扩展管理页重新加载。GitHub Actions 在 Node.js 22 和 24 上运行同样的检查并生成扩展安装包。

自动化测试涵盖公式去重与恢复、货币文本、代码、合并表格、XSS、来源与 Host 校验、异步任务去重、重启中断、token 缓存和限流。飞书 HTTP 请求使用模拟接口验证；真实租户权限、飞书端显示与编辑效果需按配置教程的验收步骤联调。

## 当前边界

- 图片以原图链接保留；纯图片、Canvas 或缺少源码/MathML 的 SVG 公式不做 OCR。
- 支持普通网页主框架中已加载的 DOM；跨域 iframe、闭合 Shadow DOM、浏览器 PDF 查看器和虚拟列表中尚未加载的内容不在本版范围。长页面请先滚动加载，再提取，或选择所需内容。
- 不支持的公式保留 LaTeX 源码并提示；本地 KaTeX 预览与飞书内置版本可能有差别。嵌套表格展开为文字；列表层级、编号起点和复杂 CSS 布局不逐像素复刻。
- 大表格会分片；跨分片的合并区域在各分片重复内容。单个表格最多 5000 个网格位置、100 列。
- 文本块有大小限制，因此长段落和长代码会拆为多个块。页面 HTML 上限 5 MB，内容块上限 3000；超出时使用选区模式。
- 服务重启会把未完成任务标为中断，保留已知文档链接，不自动恢复写入。任务记录最多保留 500 条；同一 UUID 在记录保留期间去重。
- 初版服务仅适合本机单用户使用。正式团队版可进一步增加飞书 OAuth、组织级部署和更细的任务恢复。

## 数据与权限

扩展只申请 `activeTab`、`scripting`、`storage` 和 `127.0.0.1` 访问权限。点击提取后才读取当前标签页，捕获阶段移除表单字段；只保留普通网页链接。

页面快照在本机内存中处理；点击保存后，提取出的内容和原网页 URL 会发送到飞书。URL 可能带查询参数，保存前请检查来源。扩展配对码存放于浏览器本地存储（不使用同步存储）；飞书凭据保存于权限为 `0600` 的 `.env`；`.data/jobs.json` 仅保存任务状态、内容指纹和文档 ID，不保存正文与密钥。日志不输出凭据。

本地接口绑定 `127.0.0.1`，校验 Host、Origin 和 Bearer 配对码。不要把本服务映射到公网。`.env`、`.data`、依赖和构建输出均已加入 `.gitignore`。
